# Experimental verb list with pronominal verbs

`verbs_lefff.json` is a single-file verb list in which **pronominal verbs are their
own entries**: `lever` and `se lever` are separate keys, as are `laver` / `se laver`,
and verbs that only exist pronominally (`s'évanouir`, `se souvenir`) appear only in
their pronominal form.

It is generated by `tool/lefff/build_lefff_verbs.py` from the Lefff 3.4 lexicon
(see `tool/lefff/README.md`). It is **not** registered in `pubspec.yaml` and nothing
in the app loads it yet.

| | Count |
|---|---|
| Entries | 11,336 |
| Plain verbs (`lever`) | 7,686 |
| Pronominal verbs (`se lever`) | 3,650 |
| of which `essential` | 134 |
| of which `lexicalised` | 1,059 |
| of which `reflexive` | 2,457 |

## Shape

```json
{
  "source": "...", "lefff_version": "3.4", "generated_by": "tool/lefff/build_lefff_verbs.py",
  "verb_count": 11336,
  "counts": {"plain": 7686, "pronominal": 3650, "essential": 134, "lexicalised": 1059, "reflexive": 2457},
  "verbs": {
    "lever":    { "...tense codes...", "zipf": 4.54, "meta": { ... } },
    "se lever": { "...tense codes...", "zipf": 4.54, "meta": { ... } }
  }
}
```

Every entry uses the same tense codes, slot order and `"NA"` convention as
`assets/verbs/verbs_*.json` (see `../README_verb_tiers.md`), so `Verb.fromJson`
loads it unchanged and ignores the extra `meta` object. Entries are written one per
line, sorted by base verb with the plain entry before its pronominal one.

```json
"se lever": {
  "P": ["me lève", "te lèves", "se lève", "nous levons", "vous levez", "se lèvent"],
  "I": ["me levais", "te levais", "se levait", "nous levions", "vous leviez", "se levaient"],
  "Y": ["NA", "lève-toi", "NA", "levons-nous", "levez-vous", "NA"],
  "G": ["se levant"],
  "K": ["levé", "levés", "levée", "levées"],
  "W": ["se lever"],
  "zipf": 4.54,
  "meta": {
    "pronominal": true,
    "pronominal_kind": "lexicalised",
    "base": "lever",
    "pronoun_optional": false,
    "elides": false,
    "auxiliary": "être",
    "impersonal": false,
    "impersonal_only": false,
    "prepositions": ["de", "contre"],
    "glosses": [],
    "senses": {"pronominal": 4, "reflexive": 2},
    "inflection_class": "v-er:std",
    "zipf_source": "base:verbs_common.json",
    "tier": "common"
  }
}
```

### Pronominal forms

The reflexive pronoun is composed into the simple tenses (`me lève`, `m'évanouis`,
`nous levons`), postposed in the imperative (`lève-toi`, `levons-nous`,
`levez-vous`) and prefixed to the present participle (`se levant`). The past
participle (`K`) is left bare because agreement belongs to compound-tense logic.
Elision follows the vowel / mute-h rule; aspirated-h verbs do not elide
(`je me hâte`, `se heurter`).

## `meta` fields

### On pronominal entries

| Field | Meaning |
|---|---|
| `pronominal` | always `true` |
| `pronominal_kind` | `essential`: the verb has no non-pronominal personal use (`s'évanouir`, `se souvenir`, `s'abstenir`). `lexicalised`: the plain verb exists but the pronominal form has its own lexicalised meaning(s) (`se lever` = get up, `se moquer`, `se plaindre`, `se rendre`). `reflexive`: only the derived reflexive / reciprocal / middle / passive reading exists, the pronoun is the object (`se laver`, `se regarder`). |
| `base` | key of the regular verb in this file, or `null` for `essential` verbs with no plain entry |
| `pronoun_optional` | Lefff marks the pronoun as optional for at least one sense (`(se) bagarrer`, `(s')accroître`) |
| `elides` | the pronoun elides before this verb (`s'` rather than `se`) |
| `auxiliary` | always `être` |
| `impersonal`, `impersonal_only` | has an impersonal sense (`il s'agit de`); `impersonal_only` when no personal pronominal sense exists (`s'agir`) |
| `prepositions` | prepositions the pronominal verb governs, most frequent first (`se souvenir` → `de`, `s'attendre` → `à`) |
| `glosses` | English glosses Lefff attaches to a few senses (`s'attendre` → `expect`) |
| `senses` | number of `pronominal` (`@pron`) and `reflexive` (`se_moyen`) senses in Lefff |
| `inflection_class` | Lefff conjugation class (`v-er:std`, `v-ir2`, `v-re3`, ...) |
| `zipf_source` | `base:<tier file>`: the zipf is inherited from the base verb |
| `tier` | tier the zipf falls in, using the cut-offs from `../README_verb_tiers.md` |

### On plain entries

| Field | Meaning |
|---|---|
| `pronominal` | always `false` |
| `pronominal_form` | key of the pronominal entry (`se lever`), or `null` if the verb has none |
| `auxiliary` | `avoir`, `être` or `both`, from Lefff's per-sense marks. These are sparse: `partir` reads `both`. Treat `être`/`both` as "takes être in at least one sense". |
| `impersonal`, `impersonal_only` | as above (`falloir`, `pleuvoir` are `impersonal_only`) |
| `prepositions`, `glosses`, `inflection_class`, `tier` | as above |
| `senses` | number of `active`, `pronominal` and `reflexive` senses |
| `zipf_source` | the tier file the forms and zipf were copied from |

## How this differs from the tier files

- Seven non-verb keys in the tier files (`voici`, `voilà`, `revoici`, `revoilà`,
  `pacser`, `uw`, `uwSe`) are not carried over.
- 133 verbs that exist only pronominally have no plain entry here even though the
  tier files list them bare (`évanouir`, `abstenir`, `envoler`).
- Forms are otherwise identical to the tier files; `--verify` in the generator checks
  them against the lexicon.
- 13 entries are infinitive-only defective verbs (`accroire`, `quérir`, `se parfaire`,
  `ravoir`, ...). `Verb.fromJson` returns null for them, as it does for the same
  verbs in the tier files, and `test/experimental_verbs_test.dart` allows for that.
